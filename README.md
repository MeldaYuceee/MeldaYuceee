## `~/` whoami

I'm a **Computer Engineering student** interested in the point where software meets the physical world.

I enjoy building systems around **embedded devices, UAVs, telemetry, real-time monitoring, computer vision and engineering simulations**.

Rather than focusing only on applications, I'm especially interested in understanding **how data moves through a system, how hardware behaves, how failures can be detected, and how software can react to them in real time.**

* 🛰️ Exploring **UAV telemetry, embedded communication & real-time systems**
* ⚙️ Building with **C/C++, Python, ESP32 & Arduino**
* 🚁 Developing **UAV mission, telemetry and simulation prototypes**
* 🔎 Interested in **anomaly detection, sensor fusion and signal-based systems**
* 🎯 Long-term goal: **aerospace, embedded systems & defense technologies**
